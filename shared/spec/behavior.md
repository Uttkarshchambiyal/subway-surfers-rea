# Rail Rush — shared behavior contract v1

Offline three-lane runner reconstructed against the Android3.61.0 Easter Ireland reference. The movement baseline comes from selected serialized reference configuration, normalized to a chosen reconstruction scale; runtime modifier precedence remains unresolved. Camera placement, routes, collisions, powers and economy include independent choices. See docs/revision/reference-parameters.md. All implementations use their requested native stack.

## Coordinates and simulation
Reconstruction world units and seconds; +X right, +Y up, forward distance D increases while renderer objects move toward +Z. Player render Z=0; render Z=D-entity.worldZ. HUD metres is a reconstruction convention. Lane positions are -35/9, 0, 35/9, normalizing the recovered 20-source-unit spacing. Fixed simulation dt=1/120; clamp render delta to .05 and use an accumulator. Paused/backgrounded runs do not advance.
Speed ramps linearly from21.3888888889 to42.7777777778, acceleration .1194909994 units/s². Update speed before distance. Lane changes use linear interpolation from current X with base duration .27s, or .54s during jetpack, divided by max(1,speed/initialSpeed). During an active transition reject repeated same-direction inputs and gate reversals on .2916666667 units of accumulated lateral travel. A reversal starts continuously from current X and scales duration by its remaining lane fraction, preserving lateral speed. Lane selection uses ties-to-even rounding. Reject boundary inputs without resetting interpolation or the travel gate. These semantics are interpreted from retained native disassembly; full original runtime modifiers remain outside this contract.
Jump is allowed while grounded or within .15s after losing support, once per departure. Launch velocity17.391639825, gravity38.8888888889; integrate vy-=gravity*dt then y+=vy*dt, clamp on landing. Boots use24.5954929124 as an approximate ballistic double-height jump; the original high-jump animation curve is not reproduced. Normal analytic height3.8889 and airtime .8944s differ slightly under fixed-step integration. Down sets roll .6s and airborne velocity to at most-17.5. Standing height1.75, rolling height .65, player radius .36. Swept relative Z collision uses actual X rather than selected lane.

## States
menu -> starting (0.8 sec) -> running -> collision (0.6 sec) -> results. Pause running/starting -> paused; resume returns to prior state. Restart resets complete run state, entities, timers, RNG, distance and pools. Menu/results never advance the run. Run earnings settle once per run (including returning to menu). Avoid duplicate payout on restart. Game over animates tumble/impact and settles earnings. No paid/online revive.

## Shared route and fairness
Use shared/config/route.json, generated by scripts/generate-shared.py using LCG uint32 state=(1664525*state+1013904223) mod 2^32 seed=1337. It contains original procedural design, not extracted target data. Rows begin at96+64*rowIndex. Spawn entities within300units ahead, in sorted order. There are96canonical rows; repeat with cycle world offset=6144. Preserve relative object offsets; this gives equivalent infinite bounded routes on all platforms. PRNG vectors are supplied to detect numeric mistakes; no language default RNG is used. Route has one guaranteed obstacle-free lane in every row; row spacing is about1.50seconds at cap speed, greater than lane/jump reaction budget. Rows have 6 ground coins on the safe lane, obstacles in up to 2 other lanes, occasional ramp+train sequence and elevated coin path, and one cycling powerup every fourth row. First obstacle row is96; ramps can begin at89. Never spawn objects behind the player during a run.
Obstacle z means forward leading edge; extent is [z,z+length]. Coin/pickup z is its centre. Collision lateral overlap is abs(playerX-laneX)<1.46. Power pickup uses horizontal halfwidth1m, swept forward interval [oldDistance-1,newDistance+1], vertical halfheight1.4m around action-dependent player centre.
Entity fields: id, kind string, lane integer, z absolute first-cycle distance, y coin/pickup centre, length metres; moving trains approach at 4m/s after spawn (displacement since activation). train length 10, top=3; ramp length 7, top=3 and rise in forward direction. Ramp surface raises floor smoothly as player traverses it; floor=3*min(1,(D-ramp.z+.36)/length) while D inside ramp, accounting for forward foot radius; train tops support y=3 until end, then player falls. Jumping from a train preserves floor; below roof height, side/front train collisions are fatal. Platforms should show a sloping ramp rather than a solid box. Barrier top 1.05; overhead lower edge 1.1 and upper edge 2.6. Swept collision on leading/trailing occupancy; no collision with train if feet at roof within tolerance .08. Ramp entry nonfatal; landing on train supported.

## Collectibles and score
Coins use horizontal halfwidth .65m, swept forward interval [oldDistance-.7,newDistance+.7] and vertical halfheight .85 around player centre (height y+.9 or y+.32 rolling). Magnet captures coins within 10.5 metres horizontal/forward and 4 vertical metres, spanning both outer lanes. Captured coins remain active while flying to the raised-hand magnet along a curved path. Flight duration is 0.34 + horizontal/forward range * 0.02 seconds. Pause freezes flight; expiry lets captured coins finish; collision allows pending arrivals before settlement; restart clears them. Credit each coin exactly once on arrival. Ordinary body pickups still collect immediately. Cumulative distanceScore starts at0. At the end of each running tick after interactions, add (floor(newDistance)-floor(oldDistance))*3*(multiplierActive?2:1). Score=distanceScore+runCoins*10. Multiplier only doubles newly crossed metres; expiration never removes earned score. Best persists. Powerups in route are real collision pickups, 1m range.
Power timers tick only in running state. Recollection refreshes duration, no additive stacking. Distinct effects coexist. Jetpack suppresses ground collision and smoothly raises feet to 8; follows elevated trail at y=8.9. When it expires, fall with gravity and grant 1.5 seconds collision grace so landing remains safe. Boots only change next jump launch velocity. Multiplier doubles the score earned for newly crossed metres. Magnet changes pickup range and visibly draws coins into the held prop. Board activated with B/double-tap/BOARD button: consumes one inventory board, 20sec duration, negates one crash, then removes nearby obstacles within 16m and grants 1sec grace. Duration expiration removes protection without changing trajectory. Collected board grants 20sec protection directly. Each new save gets 3 boards, buy 3 for 30 earned coins.

## Input, presentation and lifecycle
Keyboard A/D or arrows lane, W/up/space jump, S/down roll, B board, Escape/P pause. Touch swipes min24 logical px, dominant axis; two taps within .28sec activate board; tap menus uses native controls. Starting sequence accepts lane/jump only once running. Pause on blur/visibility loss/background/interruption. Resume explicit to prevent unexpected crashes. Audio starts only on interaction; generated original WAV effects/music in shared/assets/audio, local playback, mute+volume functional; suspend music when paused/backgrounded. Camera perspective config in gameplay.json; position X follows 0.75*playerX and target X follows 0.55*playerX; camera and target Y lift by .82*playerY when flying or feet>3m, otherwise .12*playerY. This framing was corrected after actual portrait screenshots showed clipping. Jetpack smoothing uses y+=(8-y)*min(1,6*dt), keep horizon and long sight lines. Character pose responds to run phase, jump tuck, roll and crash. Safe insets, portrait HUD; desktop remains usable. Ireland reference inspired presentation uses orange ballast, cream/yellow commuter trains, green freight containers, cliffs, green/pink foliage, sheep, a lighthouse, and a red-cap runner with cream hoodie and blue vest/jeans. Geometry and animation remain simplified replacements.
