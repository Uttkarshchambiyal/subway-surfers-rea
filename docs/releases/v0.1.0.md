# Subway Surfers / REA — first public study build

An unofficial, offline reconstruction for the browser, native Android, and iOS Simulator, using recovered Subway Surfers 3.61.0 character/environment assets and REA-assisted investigation.

## In this build

- A visible, raised-hand magnet attracts spinning coins from all three tracks along curved gold trails. Coin credit and the arrival pulse happen when the coin reaches the magnet.
- Lane changes, jumping, rolling, ramps, train roofs, jetpack, super sneakers, multiplier, hoverboard protection, local progression and offline browser loading.
- Three native stacks: TypeScript/Three.js, Kotlin/GLES, and Swift/SceneKit, with shared configuration and simulation vectors.
- Animated README artwork, screenshots, build instructions, recovered-asset provenance and retained verification reports.

## Verification and limits

Browser: 43 unit tests, all 10 production sections, 600 accelerated simulated seconds, desktop/portrait magnet fixtures, offline reload and touch checks passed. Android: 21 JVM tests plus native emulator magnet captures passed. Swift: 44 Foundation engine checks passed. The shared scenario passed 154 numeric comparisons with zero difference.

The iOS Simulator app compiled, but its execution remains unverified because the build host had no installed iOS Simulator runtime. Physical phones and iPhone signing are untested. Recovery does not establish complete original Unity/Animator fidelity. The animated README and magnet screenshots are controlled fixtures, clearly labeled in the repository.
